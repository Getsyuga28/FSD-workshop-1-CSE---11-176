# Student Management System

A web-based Student Management System developed using React.js, Node.js, and Express.js.

The application allows users to add, view, search, update, and delete student records through a simple and responsive interface.

## Features

- Add new student
- View all students
- Search students by ID or name
- Update student details
- Delete students
- Student ID uniqueness validation
- Email validation
- Mobile number validation
- Semester validation
- Responsive user interface
- REST API integration
- In-memory data storage

## Technologies Used

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Vite

### Backend
- Node.js
- Express.js
- CORS

### Data Storage
- JavaScript in-memory array

> Student data is stored temporarily in memory and is reset whenever the backend server is restarted.
